バックアップ

GitHub Pages版はブラウザのLocalStorageへ保存します。端末変更やブラウザデータ削除に備えて定期的にバックアップしてください。

使い方

  1. netkeibaの「出馬表」をコピーして上段へ貼り付け。
  2. 各馬の近走テキストをまとめて下段へ貼り付け。
  3. 「解析して予想」を押す。
  4. 予想を保存。
  5. レース後、保存レースで 7-2-9 のように結果入力。
  6. 結果保存時に自動回顧と学習重み更新。

GitHub Pagesは静的サイトなのでPython/Streamlitは動きません。この版はJavaScriptだけで同じ予想ロジックを動かしています。
